# News
Android-приложение для чтения новостей по интересующим темам. Пользователь добавляет подписки на ключевые слова, получает ленту статей из [News API](https://newsapi.org/), сохраняет понравившиеся материалы в избранное и читает их без интернета.
## Возможности
- **Подписки на темы** — добавление и удаление тем, фильтрация ленты по выбранным подпискам
- **Лента статей** — заголовок, описание, изображение, источник и дата публикации
- **Детали статьи** — полный текст описания, открытие в браузере, шаринг
- **Избранное (офлайн)** — сохранение статей в локальную БД; список и детали доступны без сети
- **Настройки** — язык поиска (EN, RU, FR, DE), интервал фонового обновления (15 мин – 24 ч), уведомления о новых статьях, обновление только по Wi‑Fi
- **Фоновое обновление** — периодическая подгрузка новостей через WorkManager
## Экраны
| Экран | Описание |
|-------|----------|
| **My News** | Подписки, лента, обновление и очистка кэша |
| **Детали статьи** | Полное описание, избранное, Read / Share |
| **Избранное** | Сохранённые статьи, работа офлайн |
| **Настройки** | Язык, интервал, уведомления, Wi‑Fi |
## Технологии
- **Kotlin**, **Jetpack Compose** (Material 3)
- **Navigation Compose**, **Hilt**
- **Room** — кэш ленты и таблица избранного
- **DataStore** — настройки
- **Retrofit** + **kotlinx.serialization** — News API (`v2/everything`)
- **Coil 3** — загрузка изображений
- **WorkManager** — фоновое обновление
Архитектура: `data` → `domain` → `presentation` (Clean Architecture, один модуль `:app`).
## Требования
- Android 8.0+ (API 26+)
- JDK 11
- API-ключ [News API](https://newsapi.org/register)
## Сборка и запуск
1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   cd News
Создайте в корне проекта файл keystore.properties:

NEWS_API_KEY=ваш_ключ_newsapi
Соберите и установите debug-сборку:

./gradlew :app:installDebug
Или откройте проект в Android Studio и запустите на эмуляторе/устройстве.

Ключ подставляется в BuildConfig.NEWS_API_KEY при сборке (app/build.gradle.kts). Не коммитьте keystore.properties в публичный репозиторий.

Использование
На главном экране введите тему и нажмите Add subscription.
Выберите одну или несколько подписок в чипах — отобразится лента статей.
Нажмите Update articles (иконка обновления) для ручной загрузки.
Тап по карточке — экран деталей; иконка сердца — добавить/убрать из избранного.
Иконка избранного в шапке — сохранённые статьи (доступны без интернета).
Settings — язык поиска, интервал обновления, уведомления и режим Wi‑Fi.
